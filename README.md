## `01 / Behind the code`

I’m a developer who likes owning the **whole story** of a product.

The interface matters. So do the interactions, the architecture, and the quiet logic behind every tap. I build for the web with **HTML, CSS, JavaScript, and React**, create native Android experiences with **Kotlin**, and work with **Python and SQL** on the systems underneath.

> **I don’t want to make things that only work. I want them to leave a trace.**

## `03 / How I think`

```text
                THE PART YOU SEE                 THE PART THAT POWERS IT

              ┌──────────────────┐              ┌──────────────────┐
              │ UI / INTERACTION │              │ LOGIC / DATA     │
              │ HTML · CSS       │              │ Python · SQL     │
              │ React · Android  │      ⇄       │ APIs · Systems   │
              └──────────────────┘              └──────────────────┘

                         One developer. Every layer.
```

- **Clarity before decoration** — every detail should have a reason.
- **Motion with restraint** — interaction should guide, not distract.
- **Mobile is a first-class experience** — never a compressed desktop layout.
- **Code should age well** — understandable, maintainable, and intentional.
